🍏 Apple Website Clone (Pure CSS Mastery)
Project Description
A pixel-perfect replica of Apple's official website built entirely with vanilla HTML, CSS, and JavaScript—no frameworks or libraries. This project showcases deep CSS understanding and attention to detail.

Key Features
🎯 Exact visual replication of Apple's design

✨ Pure CSS animations and transitions

📐 Custom grid system without Bootstrap

🔄 Scroll-based effects and parallax

📱 Mobile-first responsive design

Tech Stack
Core: HTML5, CSS3, Vanilla JavaScript

Animations: CSS Keyframes & Transitions

Layout: CSS Grid & Flexbox

Icons: Font Awesome
